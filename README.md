# Dashboard Financiero (SQL + Excel)

## Objetivo
Registro de transacciones + consultas SQL para balance y gastos + dashboard en Excel.

## Stack
- SQL
- Excel
- Dataset sintético

## Cómo ejecutar (rápido)
1) Crear tabla: `sql/schema.sql`
2) Cargar `data/transactions.csv`
3) Ejecutar `sql/queries.sql`
4) Abrir `excel/finance_dashboard.xlsx`

## Estructura
```
05-personal-finance-sql-excel/
├── data/transactions.csv
├── sql/
└── excel/finance_dashboard.xlsx
```
